# พอร์ตลงทุน

เว็บแอปส่วนตัวสำหรับคนที่ DCA อยู่แล้วและอยากรู้ว่าหุ้นที่ถือ "ถึงจุดน่าซื้อเพิ่มหรือยัง"

- **ภาพรวม** — มูลค่าพอร์ต กำไร/ขาดทุน กราฟย้อนหลัง สัดส่วนสินทรัพย์
- **สัญญาณซื้อ** — คะแนนน่าซื้อ 0–100 ของแต่ละตัว ยอดที่ควรซื้อเพิ่มรอบนี้ และขั้นบันไดราคา
- **หุ้นน่าสนใจ** — รายชื่อพร้อม thesis ความเสี่ยง และการวิเคราะห์เทียบกับพอร์ตที่มีอยู่
- **จัดการพอร์ต** — แก้จำนวน ต้นทุน วิธีซื้อ และเพดานน้ำหนัก

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `data/portfolio.json` | สินทรัพย์ที่ถือ จำนวน ต้นทุน และงบซื้อสะสมต่อเดือน |
| `data/watchlist.json` | รายชื่อหุ้น/ETF ที่ติดตาม พร้อม thesis |
| `scripts/update_data.py` | ดึงราคาจาก Yahoo Finance แล้วคำนวณคะแนน เขียนลง `data/market.json` |
| `.github/workflows/update-data.yml` | รันสคริปต์อัตโนมัติวันละ 2 รอบ |
| `index.html`, `assets/` | หน้าเว็บ (static ไม่ต้อง build) |

## เปิดใช้งาน

1. merge เข้า branch `main`
2. Settings → Pages → Source: *Deploy from a branch* → `main` / root
   (repo ต้องเป็น public หรือใช้ GitHub Pro)
3. Settings → Actions → General → Workflow permissions → *Read and write*
4. Actions → *Update market data* → Run workflow เพื่อดึงราคารอบแรก

รันในเครื่อง:

```bash
pip install -r requirements.txt
python scripts/update_data.py
python -m http.server 8000   # เปิด http://localhost:8000
```

## Symbol

ใช้รหัสของ Yahoo Finance: หุ้นสหรัฐ `NVDA`, หุ้นไทย `PTT.BK`, คริปโต `BTC-USD`,
กองทุนรวมไทยใช้รหัส `0P…​.BK` (ค้นชื่อกองใน finance.yahoo.com)
สินทรัพย์ที่ Yahoo ไม่มีราคา ให้ใส่ `"manual_price"` ในรายการนั้นแทน (จะนับมูลค่าแต่ไม่มีสัญญาณ)

สินทรัพย์ที่ Yahoo ไม่มีราคาโดยตรงใช้ราคาประมาณ (กำหนดใน `SYNTHETIC` ของ `scripts/update_data.py`):

- `SP500-THB` — กองทุนดัชนี S&P 500 ไม่ป้องกันค่าเงิน ประมาณจาก IVV × USD/THB
- `GOLD965-THB` — ทองคำแท่ง 96.5% ต่อ 1 บาททอง ประมาณจากราคาทองโลก × USD/THB × 0.4729

กรอกราคา/NAV จริงล่าสุดในแท็บ "จัดการพอร์ต" หนึ่งครั้งเพื่อปรับเทียบ หลังจากนั้นราคาจะขยับตามสินทรัพย์อ้างอิง

## ความเป็นส่วนตัว

`data/portfolio.json` เก็บเฉพาะรายชื่อสินทรัพย์ (จำนวนเป็น 0) จำนวนและต้นทุนจริงกรอกบนหน้าเว็บและเก็บใน
localStorage ของเบราว์เซอร์เท่านั้น ย้ายเครื่องด้วยปุ่มดาวน์โหลด/นำเข้าไฟล์

## คะแนนน่าซื้อ

| องค์ประกอบ | น้ำหนัก | วัดอะไร |
|---|---|---|
| ส่วนลดจากจุดสูงสุด | 35% | drawdown จากจุดสูงสุด 52 สัปดาห์ เทียบกับประวัติ 5 ปีของตัวเอง |
| เทคนิคอล | 25% | RSI 14, ระยะห่างจากเส้น 200 วัน, Bollinger %B |
| แนวโน้มระยะยาว | 20% | ราคาเทียบเส้นแนวโน้ม log-linear 5 ปี |
| มูลค่าพื้นฐาน | 20% | ส่วนต่างราคาเป้าหมายนักวิเคราะห์และ PEG (เฉพาะหุ้นรายตัวที่ดึงข้อมูลได้) |

ขนาดไม้: งบสะสมต่อเดือนแบ่ง 3 หน่วย — คะแนน 45–59 ซื้อ 0.5 หน่วย, 60–74 ซื้อ 1 หน่วย,
75+ ซื้อ 1.5 หน่วย รวมไม่เกินงบและไม่เกินเพดานน้ำหนักของแต่ละตัว

คะแนนบอกเพียงว่าราคาถูกเมื่อเทียบกับอดีตของตัวเอง ไม่ใช่คำแนะนำการลงทุน
